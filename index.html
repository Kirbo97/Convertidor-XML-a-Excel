XLSX

Conversor de Reportes ATS de XML a Excel

Este conversor solo funciona con los XML de los Reportes de ATS, cualquier otro no generara el excel correctamente.

1. Carga tu XML

Elige un archivo .xml o pega el texto completo del XML.

O pega el contenido
Todavía no has cargado ningún XML.
Procesando el XML y creando el Excel...

2. ¿Qué incluye el Excel?

01Datos generalesInformación del contribuyente y del período.
02ComprasDetalle de compras con sus campos anidados.
03VentasDetalle de ventas y formas de pago.
04Ventas establecimientoTotales correspondientes a cada establecimiento.

Se aplican encabezados azules, texto blanco en los títulos, filtros, primera fila inmovilizada y formato de texto en las columnas que deben conservar ceros iniciales.

El procesamiento se realiza localmente en tu navegador. No se guarda ni se transmite el XML.
